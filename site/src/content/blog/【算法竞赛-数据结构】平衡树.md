## 二叉搜索树(BST)

### 定义

BST(binary Search Tree)的定义如下：

1. 节点的左子树包含的节点的值小于该节点的值

2. 节点的右子树包含的节点的值大于该节点的值

3. 节点的左子树和右子树都是BST

   

<span id="more"></span>

BST的数据结构包含指向左右孩子的指针，以及一个表示该节点的权值。BST的初始化构建可以利用插入操作完成，BST支持插入、查找、遍历、删除等操作。

```c++
struct node{
    int value;
    node *left,*right;
    node(int x){value=x;left=right=NULL;}
};
typedef node* BSTree;
BSTree newTree(){
    return NULL;
}
```



### BST两种极端情况

1. 完全二叉树，所有节点尽量填满树的每一层。此时的查询复杂度最低，为$O(log_2n)$。

2. 退化成链表，每层只有一个节点的二叉树。此时的查询复杂度最高，为$O(n)$。

   

所以二叉搜索树的查询复杂度为$O(log_2n)\sim O(n)$。

### 插入

二叉搜索树的构造过程，也就是将节点不断插入到树种适当位置的过程。该操作与查询操作基本相同。

插入节点的过程是比较元素值是否相等，若相等则返回已存在，不相等则判断大小情况，迭代查询左右子树直到找到相等的元素，或者子节点为空，则将节点插入该空节点位置。

单个节点的构造复杂度和查询找到是相同的的，均为$O(log_2n)\sim O(n)$。

```c++
BSTree insert(BSTree t,int x){
    if(t == NULL){
        t = new node(x);
        return t;
    }
    if(t->value==x)return t;
    if(t->value>x){
        if(t->left==NULL)t->left=new node(x);
        else insert(t->left,x);
    }
    else {
        if(t->right==NULL)t->right=new node(x);
        else insert(t->right,x);
    }
    return t;
}
```



### 查找

查询节点的过程是，比较元素值是否相等，相等则返回，不相等则判断大小情况，迭代查询左右子树，直到找到相等的元素，或子节点为空，返回节点不存在。

```c++
BSTree find(BSTree t,int x){
    if(t==NULL)return t;
    if(t->value==x)return t;
    if(t->value>x)return find(t->left,x);
    else return find(t->right,x);
}
```



### 遍历

遍历BST和遍历普通二叉树一样，可以先序遍历、中序遍历和后序遍历、以及广度优先搜索(BFS)。这里就不进行赘述了。

### 删除

BST的删除删除包括两个步骤，查找和删除。

节点的删除包含了三种状态：

1. 被删除的节点出度为0

2. 被删除的节点出度为1

3. 被删除的节点出度为2

   

第一种情况，该节点无子树，删除后并不影响BST的结构特性，可以直接删除。即该节点为叶结点时，可以直接删除。

第二种情况，该节点有一颗左子树或者一颗右子树，删除该节点，为了保证BST的结构完整，需要将该子树上移到删除节点的位置上。

第三种情况，该节点同时拥有左右两颗子树。删除节点后，我们需要维持BST的结构完整，需要将**左子树**中的最大节点上移到被删除节点的位置，以此来满足BST的性质。

```c++
bool del(BSTree t,int x){
    BSTree tmp=find(t,x);
    if(tmp==NULL)return false;
    if(tmp->left==NULL&&tmp->right==NULL){
        delete tmp;
        return true;
    }
    if(tmp->left==NULL||tmp->right==NULL){
        if(tmp->left){
            BSTree D=tmp->left;
            tmp->left=D->left;
            tmp->right=D->right;
            tmp->value=D->value;
            delete D;
        }else{
            BSTree D=tmp->right;
            tmp->left=D->left;
            tmp->right=D->right;
            tmp->value=D->value;
            delete D;
        }
    }
    if(tmp->left!=NULL&&tmp->right!=NULL){
        BSTree D=tmp->left;
        while(D->right!=NULL)D=D->right;
        tmp->value=D->value;
        del(D,D->value);
    }
}
```



### 总结

二叉搜索树的节点查询、构造和删除性能，与树的高度相关，如果二叉搜索树能够更“平衡”一些，避免了树结构向线性结构的倾斜，则能够显著降低时间复杂度。二叉搜索树的存储方面，相对于线性结构只需要保存元素值，树中节点需要额外的空间保存节点之间的父子关系，所以在存储消耗上要高于线性结构。

## 替罪羊树(SGT)

暴力即是优雅。

### 简介

替罪羊树(Scapegoat Tree),是平衡树中相对简单的一种。

替罪羊树可以当作一棵非常暴力的二叉搜索树(BST)，它在子树不平衡时会进行暴力重构，此外和BST没有其他区别。

本文使用数组实现替罪羊树。

### 定义

替罪羊树的节点包括什么：

1. $ls$,$rs$:节点，记录左右儿子。

2. $val$:该节点的值。

3. $cnt$:有多少个值为$x$的数。

4. $size,sh,cur$: $size$表示以该节点为根的子树内有多少个节点(不重复)，$sh$表示有多少个有效节点的个数(就是$cnt$的和)，$cur$表示以该节点为根的子树内的真节点个数(除去标记删除的节点且，不重复)。

   

```c++
const double alpha=0.7;//重构系数 
struct node{
	int ls,rs;//左右子树节点 
	int size,sh,cur;//子树大小(每个节点记录一次)和子树节点(子树cnt之和) 和子树真节点(每个节点记录一次) 
	int val;//该点权值 
	int cnt;// 记录重复点个数 
	node(){
		ls=rs=0;
		size=sh=cur=0;
		val=0;
		cnt=0;
	}
}a[MAXN];
int root=0;
int rt[MAXN],crt=0;
int cnt=0;
```

$root$记录根节,点$rt$数组用来记录重构中的中序遍历结果。

$cnt$用来标记新的树节点。

### 重构子树

首先，判定一个节点是否应该重构。我们引入一个常量$\alpha$,一般$\alpha$的取值在$[0.7,0.8]$之间，若某节点的子节点大小占它本身大小的比例超过$\alpha$,则对该子树重构。另外，替罪羊树删除节点是采用惰性删除(即标记删除节点，并不真正删除节点信息)，已经被删除的节点过多也会影响数据结构的效率。因此若未被删除的子树大小占总大小的比例低于$\alpha$,则同样重构。

```c++
bool judge(int k){
	return a[k].cnt&&
		(alpha*a[k].size<=max(a[a[k].ls].size,a[a[k].rs].size)||
		a[k].cur<=alpha*a[k].size);
}
```

重构分成两部分，需要将子树以中序遍历结果存储，再二分重新建树，返回根节点。

```c++
void LDR(int k){ //中序遍历 
	if(!k) return;
	LDR(a[k].ls);
	if(a[k].cnt) rt[++crt]=k;//删掉空节点 
	LDR(a[k].rs);
	return;
}

int rebuild(int l,int r){//二叉树化 
	if(l==r) return 0;
	int mid=(l+r)>>1;
	a[rt[mid]].ls=rebuild(l,mid);
	a[rt[mid]].rs=rebuild(mid+1,r);
	pushup(rt[mid]);
	return rt[mid];//返回树根 
}
void rebalance(int& k){crt=0;LDR(k);k=rebuild(1,crt+1);}
```

### 插入

平衡树的几种操作的处理方式较为相似，按顺序判定四次：到达空节点，找到对应节点，小于向左，大于向右。然后处理这四个关系。

插入时，到达空节点则新建节点，找到对应节点则`a[k].cnt++;`。递归途中从下至上合并子节点，递归结束后，途径的节点可重构的要重构。

```c++
void pushup(int k){//参考线段树pushup 从下至上合并 
	a[k].size=a[a[k].ls].size+a[a[k].rs].size+1;
	a[k].sh=a[a[k].ls].sh+a[a[k].rs].sh+a[k].cnt;
	a[k].cur=a[a[k].ls].cur+a[a[k].rs].cur+int(a[k].cnt!=0);
	return;
}
void insert(int& k,int x){//插入节点 
	if(!k){
		k=++cnt;
		if(!root) root=1;
		a[k].val=x,a[k].ls=a[k].rs=0;
		a[k].cnt=a[k].size=a[k].sh=a[k].cur=1;
	}else{
		if(a[k].val==x) a[k].cnt++;
		else if(x<a[k].val) insert(a[k].ls,x);
		else insert(a[k].rs,x);
		pushup(k);
		if(judge(k)) rebalance(k);
	}
}
```

### 删除

惰性删除，到达空结点则忽略，找到对应结点则 `a[k].cnt--`。递归途中从下至上合并子节点，递归结束后，可重构节点要重构。

```c++
void del(int& k,int x){//删数x 
	if(!k)return ;
	if(a[k].val==x)
		a[k].cnt--;
	else{
		if(a[k].val>x) del(a[k].ls,x);
		else del(a[k].rs,x);
	}
	pushup(k);
	if(judge(k)) rebalance(k);
}
```

### 查找

#### at

给定名次，返回该名次上的权值。到达空结点说明无此名次，找到对应结点则返回其权值。

```c++
int at(int k,int x){//查排名为x的数 
	if(a[k].ls==a[k].rs) return a[k].val;
	if(x<=a[a[k].ls].sh) return at(a[k].ls,x);
	else if(x>a[a[k].ls].sh&&a[a[k].ls].sh+a[k].cnt>=x) return a[k].val;
	else return at(a[k].rs,x-a[a[k].ls].sh-a[k].cnt); 
}
```

#### lower_bound

给定$x$，统计树上严格小于$x$的数的个数。

```c++
int lower(int k,int x) {// 统计小于x的个数 	
	if(!k) return 0;	
	if(a[k].cnt&&a[k].val==x) return a[a[k].ls].sh;	
	else if(x<a[k].val) return lower(a[k].ls,x);	
	else return a[a[k].ls].sh+a[k].cnt+lower(a[k].rs,x);
}
```

#### upper_bound

给定$x$，统计树上小于等于$x$的个数。

```c++
int upper(int k,int x){//统计小于等于x的个数 
	if(!k) return 0;
	if(a[k].cnt&&x==a[k].val) return a[k].cnt+a[a[k].ls].sh;
	else if(x<a[k].val) return upper(a[k].ls,x);
	else return a[a[k].ls].sh+a[k].cnt+upper(a[k].rs,x); 
}
```

## 红黑树(RBT)

### 简介

红黑树是一种工程上很常用的平衡树，它是基于AVL树进行优化的，红黑树不像AVL树一样高度平衡，它优化了AVL树添加删除操作的旋转次数，通过节点颜色，保持树的一定平衡性。在最坏情况下的复杂度也是效率高校的。C++ STL库中 `container` :`map ` 和 `set` 的底层，内存管理中的虚拟内存数据结构都是用红黑树进行实现的。

### 定义

红黑树除了是一颗二叉排序树之外，还有五个要求：

- 节点是红色的或者是黑色的
- 根节点是黑色的
- 所有的叶子节点是黑色的(叶子节点是NIL)
- 每个红色节点的子节点一定是黑色的
- 从任意一个节点到它的每个叶子节点的简单路径上，黑色节点的数量相同。

这些要求使得红黑树拥有了一个性质：从叶子节点到根节点的所有路径中，最长路径最多是最短路径的两倍(红黑相间的路径与全黑色节点路径)。这样的限制保证树的平衡性不会太差，削弱了强平衡性的好处就是，可以通过节点颜色的变换，节省旋转操作，使得树在添加删除操作后，重新平衡产生的旋转操作次数减少。

AVL树的 `rebalance` 操作，需要从修改的节点位置递归向上平衡至根节点。而RBT的插入操作最多需要旋转2次，删除操作最多需要旋转3次即可使得树重新平衡。

红黑树树节点的定义和上文替罪羊树相似，替罪羊树的删除节点操作是通过标记删除的，在节点中要记录真节点个数，但是红黑树是直接删除节点，所以它不需要记录真节点。本篇采用指针的方式实现红黑树。

```c++
enum {RED,BLACK};
struct node{
  int val;// value
  bool color;
  node *p,*ls,*rs;// parent,leftson,rightson
  int sz,Tsz,cnt;// size (once),sum of count,count of itself 
  node (){
    p = ls = rs = NULL;
    val = 0;
    color = BLACK;
    sz = Tsz = cnt = 0;
  };
```

### 左旋与右旋

旋转操作是在二叉树中的一种子树调整操作，旋转树不影响树的中序遍历结果，两种旋转互为镜像操作，并且互为逆操作。

```
        +---+                          +---+
        | Q |                          | P |
        +---+                          +---+
       /     \     right rotation     /     \
    +---+   +---+  ------------->  +---+   +---+
    | P |   | Z |                  | X |   | Q |
    +---+   +---+  <-------------  +---+   +---+
   /     \          left rotation         /     \
+---+   +---+                          +---+   +---+
| X |   | Y |                          | Y |   | Z |
+---+   +---+                          +---+   +---+

```

以右旋为例子，`parents` 节点作为旋转中心，`LeftSon` 作为旋转后的 `parents `节点, 原 `parents` 节点作为新 `parents` 节点的 `RightSon` ，原`LeftSon` 的`RightSon` 变成原 `parents` 的新 `LeftSon` 。左旋为右旋的镜像操作。

在红黑树中，原`parents` 节点和 原`LeftSon` 节点的颜色需要进行交换。

```c++
void RIGHT_ROTATE(N r){
  // change color 
  // change root 
  // check NULL
  N ls = r -> ls;
  N son = ls -> rs;
  N p = r -> p;
  swap (ls -> color,r -> color);
  r -> ls = son;
  if(son) son -> p = r;
  r -> p = ls;
  ls -> rs = r;
  ls -> p = p;
  if (p) {
    if(p -> ls == r)p -> ls = ls;
    else p -> rs = ls;
  }
  if(r == root)root = ls;
}
void LEFT_ROTATE(N r){
  N rs = r -> rs;
  N son = rs -> ls;
  N p = r -> p;
  swap (rs -> color,r -> color);
  r -> rs = son;
  if(son) son -> p = r;
  r -> p = rs;
  rs -> ls = r;
  rs -> p = p;
  if (p) {
    if(p -> rs == r)p -> rs = rs;
    else p -> ls = rs;
  }
  if(r == root)root = rs;
}
```

当根节点在旋转中被替换后，也需要注意更新根节点。处理中还需要注意空节点的问题。

### 插入

平衡树的几种操作的处理方式较为相似，按顺序判定四次：到达空节点，找到对应节点，小于向左，大于向右。然后处理这四个关系。

处理完后向上更新节点。

```c++
void pushup(N n){
  if (!n)return ;
  n -> sz = 1 + ((n -> ls == NULL )? 0 : n -> ls -> sz) + ((n -> rs == NULL )? 0 : n -> rs -> sz);
  n -> Tsz = n -> cnt + ((n -> ls == NULL) ? 0 : n -> ls -> Tsz) + ((n -> rs == NULL) ? 0 : n -> rs -> Tsz);
}
```

### 插入平衡

为了保证红黑树的五个性质，我们需要将插入节点的颜色设置为红色，如果当前节点是根节点，那么将其颜色设置为黑，这样红黑树的5个要求就满足了四条。但是这并不能保证连续两个节点的颜色都不是红色。所以需要通过旋转操作满足这一点，用来维持红黑树的平衡。

针对不同的情况，有不同的旋转方式。

- 若插入节点的父节点为黑色：

  直接完成插入。并不会影响树的平衡。

- 若插入节点的父节点为红色：

  此时出现双红冲突。这时候需要考察叔父节点的状况。

  1. 若叔父节点为红色：

     将叔父节点和父节点设置为黑色，祖父节点设置为红色，递归向上平衡祖父节点，直至平衡。若根节点被设置为红色，直接结束平衡，并将根节点还原成黑色。

  2. 若叔父节点为黑色：

     此时考察插入节点与父节点与祖父节点的位置关系。

     - 若父节点、插入节点、祖父节点在树上的结构为一条线段：

       此时对祖父节点向叔父节点方向进行旋转。

     - 若父节点、插入节点、祖父节点在树上的结构为一条折线：

       需要先将折线旋转为直线，将父节点向插入节点的反方向旋转，使得插入节点成为新的父节点，然后进入上一步进行平衡。

```c++
void RB_INSERT_FIXUP(N r){
  if(r == root){
    r -> color = BLACK; 
    pushup(root);
    return ;
  }
  if(r -> p -> color == BLACK){
    while(r != NULL){
      pushup(r);
      r = r -> p;
    }
    return ;
  }
  N p = r -> p,pp = p -> p;
  N un = (pp -> ls) == p ? (pp -> rs) : (pp -> ls);
  if(un != NULL && un -> color == RED){
    un -> color = p -> color = BLACK;
    pp -> color = RED;
    pushup(p);pushup(pp);
    RB_INSERT_FIXUP(pp);
    return ;
  }

  if(((pp -> ls == p) && (p -> ls == r))||
     ((pp -> rs == p) && (p -> rs == r))
    ){
    if(p -> ls == r){
      RIGHT_ROTATE(pp);
      pushup(pp);pushup(p);
    }else{
      LEFT_ROTATE(pp);
      pushup(pp);pushup(p);
    }
    while(p != NULL){
      pushup(p);
      p = p -> p;
    }
  } else {
    if(p -> ls == r){
      RIGHT_ROTATE(p);
      pushup(p);
      LEFT_ROTATE(pp);
      pushup(pp);pushup(r);
    }else{
      LEFT_ROTATE(p);
      pushup(p);
      RIGHT_ROTATE(pp);
      pushup(pp);pushup(r);
    }
    while(r != NULL){
      pushup(r);
      r = r -> p;
    }
  }
}
```

### 删除

通过与插入相似的的方式找到需要删除的节点，然后对 `cnt` 参数修改，若 `cnt` 参数为0，则删除该点。此时需要对将被删除的节点进行分类讨论。以被删除节点的子节点数目进行分类。

- 若该节点无子节点：

  1. 若该节点为红色：

     直接删除。

  2. 若该节点为黑色：

     这是删除操作中最复杂的部分，将放在下节分析。

- 若该节点有一个子节点：

  如果这是一颗已经平衡的红黑树，有且只有`BLACK -> RED` 这一种情况(满足第五条需求)。此时只需要删除黑色节点，然后将它的红色子节点变成黑色，替换掉原先黑节点位置即可完成平衡。

- 若该节点有两个子节点：

  找到该节点的前驱或者后继节点，将两节点的值进行替换，将操作变成删除替换后的节点。因为节点位置为前驱或者后继，所以它不可能拥有两个子节点，此情况变成上述两种之一。

```c++
void RB_DELETE(int x,N r){
  N cur = r,pre = NULL;
  while(cur != NULL){
    if(cur -> val > x) pre = cur,cur = cur -> ls;
    else if(cur -> val < x) pre = cur,cur = cur -> rs;
    else {
      cur -> cnt--; 
      break;
    }
  }
  if(cur == NULL)return ;
  if(cur -> cnt != 0){
    while(cur != NULL){
      pushup(cur);
      cur = cur -> p;
    }
    return ; 
  }
  re:;
  if(cur -> ls && cur -> rs){
    pre = cur ;
    pre = cur -> ls;
    while(pre -> rs != NULL){
      pre = pre -> rs;
    }
    swap(cur -> val, pre -> val);
    swap(cur -> cnt, pre -> cnt);
    cur = pre;
    while(pre != NULL){
      pushup(pre);
      pre = pre -> p;
    }
    goto re;
  }else if(cur -> ls || cur -> rs){
    // only BLACK -> RED
    N p = cur -> p;
    N son;
    if(cur -> ls)son = cur ->ls;
    else son = cur -> rs;
    if(p != NULL){
      if(p -> ls == cur)p -> ls = son;
      else p -> rs = son;
    }else root = son;
    son -> p = p;
    son -> color = BLACK;
    delete cur ;
    while(p != NULL){
      pushup(p);
      p = p -> p;
    }
  }else{
    if(cur == root){
      delete cur;
      root = NULL;
      return ;	
    }
    if(cur -> color == RED){
      pre = cur -> p;
      if(pre -> ls == cur)pre -> ls = NULL;
      else pre -> rs = NULL;
      delete cur;
      while(pre != NULL){
        pushup(pre);
        pre = pre -> p;
      }
    }else{
      pre = cur -> p;
      delete cur;
      RB_DELETE_FIXUP(cur,pre,0);
    }
  } 
} 
void RB_DELETE(int x){
  if(root == NULL)return ;
  else RB_DELETE(x,root);
}
```



### 删除平衡

这节单独讲如何删除单个黑色节点。

因为节点为黑色，那么删除会影响原先树的平衡。

并且影响可能会递归向上至根节点，所以需要在节点删除后，标记删除后的位置为失衡节点，然后进行平衡。

此时首先考察兄弟节点的颜色：

- 若兄弟节点的颜色为黑色：

  1. 考察兄弟节点的子节点颜色，若存在父节点、兄弟节点、兄弟节点子节点，一条线，且兄弟子节点为红，则将兄弟子节点设置为黑，然后向删除节点方向旋转父节点，完成平衡。

  2. 若存在父节点、兄弟节点、兄弟子节点为折线、且此兄弟子节点为红色，则首先旋转兄弟节点，将兄弟子节点旋转至原兄弟节点位置，此时变成第一种直线情况，然后进行第一步同样操作。

  3. 若兄弟节点没有红色子节点：

     - 此时若父节点为红色：

       替换父节点和兄弟节点颜色，完成平衡。

     - 此时若父节点为黑色：

       将兄弟节点颜色设置为红色，将失衡位置设置在父节点，递归向上处理，若平衡直至根节点，则结束平衡。

- 若兄弟节点的颜色为红色：

  则父节点向删除节点方向旋转，获得一个新的兄弟节点，重新进行平衡。

```c++
void RB_DELETE_FIXUP(N cur,N pre,int opt){// single black
  if(pre == NULL )return ; 
  N bro = (pre -> ls) == cur ? (pre -> rs) : (pre -> ls);
  if (bro == NULL) return ;
  if (bro -> color == BLACK){
    if((bro -> ls && bro -> ls -> color == RED) ||(bro -> rs && bro -> rs -> color == RED)){// bro has red son
      if(pre -> ls == cur && (bro -> rs && bro -> rs -> color == RED)){
        LEFT_ROTATE(pre);
        bro -> rs -> color = BLACK;
        if(opt == 0)
          pre -> ls = NULL;
        pushup(pre);pushup(bro);
      }else if(pre -> rs == cur && (bro -> ls && bro -> ls ->color == RED)){
        RIGHT_ROTATE(pre);
        bro -> ls -> color = BLACK;
        if(opt == 0)
          pre -> rs = NULL;
        pushup(pre);pushup(bro);
      }else if(pre -> ls == cur && (bro -> ls && bro -> ls ->color == RED)){
        N son = bro -> ls;
        RIGHT_ROTATE(bro);
        pushup(bro);
        LEFT_ROTATE(pre);
        bro -> color = BLACK;
        if(opt == 0)
          pre -> ls = NULL;
        pushup(pre);pushup(son);
      }else if(pre -> rs == cur && (bro -> rs && bro -> rs ->color == RED)){
        N son = bro -> rs;
        LEFT_ROTATE(bro);
        pushup(bro);
        RIGHT_ROTATE(pre);
        bro -> color = BLACK;
        if(opt == 0)
          pre -> rs = NULL;
        pushup(pre);pushup(son);
      }
      while(pre != NULL){
        pushup(pre);
        pre = pre -> p;
      }
    }else {
      if(pre -> color == RED){
        swap(pre -> color ,bro -> color);
        if(opt == 0){
          if(pre -> ls == cur) pre -> ls = NULL;
          else pre -> rs = NULL;
        }
        while(pre != NULL){
          pushup(pre);
          pre = pre -> p;
        }
      }else{
        bro -> color = RED;
        if(opt == 0){
          if(pre -> ls == cur) pre ->ls = NULL;
          else pre -> rs = NULL;
        }
        pushup(pre);
        RB_DELETE_FIXUP(pre,pre -> p,1);
      }
    }
  }else{// bro is red
    if(pre -> ls == cur)
      LEFT_ROTATE(pre);
    else 
      RIGHT_ROTATE(pre);
    pushup(pre);pushup(bro);
    RB_DELETE_FIXUP(cur,pre,opt);
  }
}
```

```c++
					N son = bro -> ls;
					RIGHT_ROTATE(bro);
					pushup(bro);
					LEFT_ROTATE(pre);
					bro -> color = BLACK;
					if(opt == 0)
						pre -> ls = NULL;
					pushup(pre);pushup(son);
				}else if(pre -> rs == cur && (bro -> rs && bro -> rs ->color == RED)){
					N son = bro -> rs;
					LEFT_ROTATE(bro);
					pushup(bro);
					RIGHT_ROTATE(pre);
					bro -> color = BLACK;
					if(opt == 0)
						pre -> rs = NULL;
					pushup(pre);pushup(son);
				}
				while(pre != NULL){
					pushup(pre);
					pre = pre -> p;
				}
			}else {
				if(pre -> color == RED){
					swap(pre -> color ,bro -> color);
					if(opt == 0){
						if(pre -> ls == cur) pre -> ls = NULL;
						else pre -> rs = NULL;
					}
					while(pre != NULL){
						pushup(pre);

					}

					bro -> color = RED;
					if(opt == 0){
						if(pre -> ls == cur) pre ->ls = NULL;
						else pre -> rs = NULL;
					}
					pushup(pre);
					RB_DELETE_FIXUP(pre,pre -> p,1);
				}
			}
		}else{// bro is red
			if(pre -> ls == cur)
				LEFT_ROTATE(pre);
			else 
				RIGHT_ROTATE(pre);
			pushup(pre);pushup(bro);
			RB_DELETE_FIXUP(cur,pre,opt);
		}
	}
	void RB_DELETE(int x,N r){
		N cur = r,pre = NULL;
		while(cur != NULL){
			if(cur -> val > x) pre = cur,cur = cur -> ls;
			else if(cur -> val < x) pre = cur,cur = cur -> rs;
			else {
				cur -> cnt--; 
				break;
			}
		}
		if(cur == NULL)return ;
		if(cur -> cnt != 0){
			while(cur != NULL){
				pushup(cur);
				cur = cur -> p;
			}
			return ; 
		}
		re:;
		if(cur -> ls && cur -> rs){
			pre = cur ;
			pre = cur -> ls;
			while(pre -> rs != NULL){
				pre = pre -> rs;
			}
			swap(cur -> val, pre -> val);
			swap(cur -> cnt, pre -> cnt);
			cur = pre;
			while(pre != NULL){
				pushup(pre);
				pre = pre -> p;
			}
			goto re;
		}else if(cur -> ls || cur -> rs){
			// only BLACK -> RED
			N p = cur -> p;
			N son;
			if(cur -> ls)son = cur ->ls;
			else son = cur -> rs;
			if(p != NULL){
				if(p -> ls == cur)p -> ls = son;
				else p -> rs = son;
			}else root = son;
			son -> p = p;
			son -> color = BLACK;
			delete cur ;
			while(p != NULL){
				pushup(p);
				p = p -> p;
			}
		}else{
			if(cur == root){
				delete cur;
				root = NULL;
				return ;	
			}
			if(cur -> color == RED){
				pre = cur -> p;
				if(pre -> ls == cur)pre -> ls = NULL;
				else pre -> rs = NULL;
				delete cur;
				while(pre != NULL){
					pushup(pre);
					pre = pre -> p;
				}
			}else{
				pre = cur -> p;
				delete cur;
				RB_DELETE_FIXUP(cur,pre,0);
			}
		} 
	} 
	void RB_DELETE(int x){
		if(root == NULL)return ;
		else RB_DELETE(x,root);
	}
	int lower(int x,N r){
		if(r == NULL) return 0;
		if(r -> val == x)return (r -> ls == NULL )? 0 : r -> ls -> Tsz;
		else if( r -> val > x)return lower(x,r -> ls);
		else return ((r -> ls == NULL )? 0 : r -> ls -> Tsz) + r -> cnt + lower(x,r -> rs);	
	}
	int upper(int x,N r){
		if( r == NULL)return 0;
		if( r -> val == x)return r -> cnt + ((r -> ls == NULL )? 0 : r -> ls -> Tsz);
		else if(x < r -> val) return upper(x, r -> ls);
		else return ((r -> ls == NULL )? 0 : r -> ls -> Tsz) + r -> cnt +upper(x, r -> rs);
	}
	int at(int x,N r){
		if( r == NULL )return 0;
		if (r -> ls == r -> rs) return r -> val;
		if (x <= (r -> ls == NULL ? 0 : r -> ls -> Tsz)) return at(x,r -> ls );
		else if(x > (r -> ls == NULL ? 0 : r -> ls -> Tsz) && (r -> ls == NULL ? 0 : r -> ls -> Tsz) + r -> cnt >= x)return r -> val;
		else return at( x - (r -> ls == NULL ? 0 : r -> ls -> Tsz) - r -> cnt,r -> rs); 
	}
	int lower(int x){
		// lower_bound(x) count < x
		return lower(x,root);
	}
	int upper(int x){
		// upper_bound(x) count <= x
		return upper(x,root);
	}
	int at(int x){
		return at(x,root);
	} 
	void dfs(N r){
		if(!r)return ;
```
