## 定义

**线段树**(Segment Tree)是非常常用的数据结构之一，它主要用于维护区间查询和区间修改操作，并且建立线段树，区间查询、区间修改的复杂度都为优秀的$O(log_2n)$。

## 建树

线段树是一棵平衡二叉树。母节点代表整个区间的和，越往下区间越小。每个节点$p$的左右子节点的编号分别为$2p$和$2p+1$。假设当前节点存储区间$[L,R]$的和，设$mid=\lfloor \frac{L+R}{2} \rfloor$，那么左节点存储的是$[L,mid]$，右节点存储$[mid+1,R]$的和。

我们可以通过二分递归的方式进行建树。

```c++
typedef long long ll;
ll a[100010];
struct node{
    int l,r; 
    ll val;
    ll lz;
}tree[100010<<2];//四倍空间
void build(int i,int l,int r){
    tree[i].l=l,tree[i].r=r;tree[i].lz=0;
    if(l==r){//叶子节点
        tree[i].val=a[l];
        return ;
    }
    int mid=(l+r)>>1;
    build(i*2,l,mid);
    build(i*2+1,mid+1,r);
    tree[i].val=tree[i*2].val+tree[i*2+1].val; 
    return ;
} 
```



## 区间修改

在进行区间更新时候，从最大区间开始递归向下处理，任何区间都可以由线段树上节点的范围组成。

递归过程中会出现三种情况：

1. 当前节点覆盖的区间和目标区间没有交集，这时候直接递归结束返回。
2. 当前节点覆盖的区间完全在目标区间内，这时候更新当前区间，并给这个节点打上lazy标记。递归结束。
3. 当前节点覆盖的区间部分在目标区间中，这时候将lazy标记下传至左右节点，选取当前节点的左右子节点进行递归。递归结束后更新当前节点的值。

```c++
void pushdown(int i){
    if(tree[i].lz==0)return ;
    tree[i*2].lz+=tree[i].lz;
    tree[i*2+1].lz+=tree[i].lz;
    tree[i*2].val+=tree[i].lz*(tree[i*2].r-tree[i*2].l+1);
    tree[i*2+1].val+=tree[i].lz*(tree[i*2+1].r-tree[i*2+1].l+1);
    tree[i].lz=0;
    tree[i].val=tree[i*2+1].val+tree[i*2].val;
    return ;
}
void update(int i,int l,int r,ll k){
    if(tree[i].l>r||tree[i].r<l)return ;
    if(tree[i].l>=l&&tree[i].r<=r){
        tree[i].val+=(tree[i].r-tree[i].l+1)*k;
        tree[i].lz+=k;
        return ;
    }
    pushdown(i);
    update(i*2,l,r,k);
    update(i*2+1,l,r,k);
    tree[i].val=tree[i*2].val+tree[i*2+1].val;
}
```

## 查询

查询操作和修改操作大同小异，一样的通过递归完成然后再合并子节点。

直接上代码：

```c++
ll query(int i,int l,int r){
    if(tree[i].l>r||tree[i].r<l)return 0;
    if(tree[i].l>=l&&tree[i].r<=r)return tree[i].val;
    pushdown(i);
    ll ans=0;
    ans+=query(i*2,l,r);
    ans+=query(i*2+1,l,r);
    return ans;
}
```
